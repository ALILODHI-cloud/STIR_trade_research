**Net:** M7M8 is the **right alternative if the objection to Z7Z8 is entry**.
You are not buying the last 3 bp. You *are* buying a calendar that, in the
live hike-extension regime, **does not yet lag the way Dec’28 lags Dec’27**.
June’28 has been β≈1.4 to the front since August — it is still on the hike
path, not the “spared” reds.

**How to use it:**

1. Prefer **fresh shorts here, not in Z7Z8**, if you want the GS/Barclays
   flatten family with room.
2. Do **not** size it as if Aug selloffs will pay like Z7Z8 — they haven’t.
3. The trade **needs** June’28 to start lagging (path capped before mid-2028).
   If the ECB hike path **extends through Jun’28**, M7M8 **steepens** and this
   loses while Z7Z8 can still work.
4. Tactical: add on re-steepen toward **0 to +2** (9-Sep printed +1.5); trim
   if it revisits **−8.5 / −10** without Z7Z8 having more room.
5. Implementation: recv **1× IMM27** / pay **1× IMM28**. Optional overlay:
   stay long a small residual Z7Z8 only if already on from August.

This is **not** a 2y1y vs Z26 pack and **not** long U28 / short the front.
