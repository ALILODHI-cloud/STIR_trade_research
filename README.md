# STIR trade research

Tooling and notes for evaluating developed-markets short-rate trade ideas.

```bash
pip install -r requirements.txt
python3 -m pytest tests/ -q
python3 scripts/example_meeting_pricing.py
```

See `CLAUDE.md` for conventions, data handling and the working agreement.
