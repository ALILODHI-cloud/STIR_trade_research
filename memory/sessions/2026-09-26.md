- Persistent personalization is repository-backed, not perfect hidden recall:
  `memory/book.md` for standing facts/conventions, `memory/trades.yaml` for
  positions, dated session files for reconstructable history. Context can
  compact; anything not written may be lost.
- Agent can autonomously fetch, calculate, build workbooks/dashboard, test,
  commit and publish while a run is active. It does not remain continuously
  awake without GitHub workflows/Cursor automations.
- Highest-value upgrades: Barchart API key or institutional feed for reliable
  unattended refresh; merge workflow to default + enable GitHub Pages; broker
  position/fill export; current FX for cross-currency DV01; OIS/fixings/options;
  daily scheduled research automation and agreed risk/target schema.
